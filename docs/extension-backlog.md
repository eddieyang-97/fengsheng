# 扩展功能清单

这里记录尚未承诺排期的未来功能。确认规则仍只记录在 `rules-decisions.md`。

- 对局持久化：服务器重启后恢复房间和进行中的对局。
- 公开对局回放：保存经过隐私处理的公开事件；不得泄露未使用的牌、牌堆顺序或过去的私下查看结果。
- 用户账号与跨设备身份。
- 自定义玩家头像上传：替换当前通用 `👤` 图标，并继续作为送花/番茄动画的起点；实现时需确定图片格式、大小限制、存储方式与内容审核策略。
- 公开匹配。
- 排名与历史战绩。
- 角色身份与角色技能。
- 新卡牌、规则变体与扩展内容。
- 更强的 AI 策略与可选难度。
- 结构化游戏事件：以带类型、隐私级别和稳定字段的事件作为日志、AI 推理、动画、音效与玩家筛选的共同数据源，逐步移除对中文公开记录文本的机器解析；迁移期间保留现有中文记录展示。
