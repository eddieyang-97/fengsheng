# 风声 Web App

《风声再临》实体版实现，支持 **2 人决斗**和 **5–8 人标准局**。

## 主要功能

- 完整实现实体牌组、功能牌、情报传递、分层反应窗口、死亡与胜负判定。
- 支持邀请链接、座位调整、随机座位、AI 补位、断线重连和 AI 临时接管。
- 支持不占座位的旁观者，并严格区分公开记录、私人通知、手牌和隐藏情报。
- 桌面与移动端均可游玩；移动端可切换公开记录和聊天，桌面端可拖动调整两者高度，并支持完整的键盘快捷操作。
- 支持对局聊天、常用表情、送花、扔番茄、游戏音效、记录筛选和私人身份推测标记。
- 游戏结束后公开所有玩家的阵营和剩余手牌，并可保留房间与座位开始新游戏。

## 开始游戏

打开：[https://fengsheng-9jnw.onrender.com](https://fengsheng-9jnw.onrender.com)

1. 输入名字，选择人数并创建房间。
2. 把邀请链接或六位房间码发给朋友。
   不占座位的朋友可选择“旁观房间”，游戏开始后也能加入旁观。
3. 玩家到齐后可调整座位；房主也可在空位添加 AI 玩家，再选择按当前座位或随机座位开始。
4. 游戏中按高亮的卡牌和按钮操作。服务器只会显示当前合法行动。
5. 对局内可使用聊天、常用表情、送花和扔番茄与其他玩家互动。

## 游戏提示

- 每人起始摸 2 张牌；回合开始摸 2 张。
- 进入传情报阶段前，手牌不得超过 7 张。
- 进入情报传递选择窗口时，如果只有一张可传递的情报，系统会自动选中该牌。
- 反应按座位顺序处理；没有可用反应时默认自动跳过，可取消勾选，并可在大厅或游戏中调整自己的等待时间。
- 房主可以在大厅或游戏中设置反应时限，默认 15 秒；修改从下一次反应开始生效。
- AI 玩家会根据公开行动、已知情报和局面收益推测其他玩家阵营，并自动完成自己的行动与反应。
- 真人玩家断线后，房主可让 AI 临时接管其座位；原玩家重连时会自动取回控制权。
- 旁观者只会看到公开牌面、公开阵营和行动记录，不会看到手牌或获得操作权限。
- 玩家和旁观者均可参与对局聊天并使用常用表情；聊天记录会在当前对局内保留。
- 玩家可点击其他玩家的头像送花或扔番茄；这些互动只播放动画，不影响游戏流程。
- 游戏提供摸牌、出牌、传递情报和烧毁等音效，可随时静音。
- 公开记录可按相关玩家筛选；玩家也可为其他玩家添加仅自己可见的推测身份标记。
- 桌面端的公开记录与聊天侧栏可拖动调整两部分的高度。
- 有玩家断线时游戏暂停；房主可将其判定死亡后继续。
- 死亡玩家不能进行游戏操作，身份会立即公开；死亡房主仍可使用房间管理功能。
- 游戏结束后会公开所有玩家的阵营和剩余手牌；房主可选择“新游戏”，让所有玩家保留房间和座位并返回大厅。

## 键盘快捷键

可在游戏设置中查看分组说明或关闭键盘快捷键。输入聊天消息、使用下拉菜单或操作表单时，快捷键会自动停用；用鼠标选择手牌后仍可直接使用对应的功能牌快捷键。

| 分类 | 按键 | 操作 |
| --- | --- | --- |
| 通用 | `1`–`9` | 选择对应位置的手牌 |
| 通用 | `←` / `→` | 切换可用手牌 |
| 通用 | `Enter` | 确认当前唯一的主要操作 |
| 通用 | `K` | 打开弃牌堆 |
| 通用 | `Esc` | 取消选择或关闭弹窗 |
| 流程 | `T` | 进入情报传递阶段 |
| 流程 | `S` | 跳过当前反应或锁定窗口 |
| 决定 | `A` | 接受情报 |
| 决定 | `D` | 不接收情报；选择弃牌时确认当前手牌 |
| 功能牌 | `L` | 锁定 |
| 功能牌 | `F` | 增援 |
| 功能牌 | `G` | 机密文件 |
| 功能牌 | `R` | 掉包 |
| 功能牌 | `I` | 截获 |
| 功能牌 | `U` | 调虎离山 |
| 功能牌 | `P` | 破译 |
| 功能牌 | `B` | 烧毁（目标唯一时） |
| 功能牌 | `O` | 离间（目标唯一时） |
| 功能牌 | `C` | 识破 |
| 功能牌 | `M` | 选择秘密下达 |
| 功能牌 | `Q` / `W` / `E` | 使用秘密下达并依次宣布听风 / 看雨 / 日落 |
| 情报传递 | `Q` / `W` / `E` / `R` / `T` / `Y` / `U` | 按座位顺序选择当前显示的直达接收者 |

快捷键会根据当前窗口解释，因此情报传递中的 `R` 不会与反应窗口中的掉包冲突。

完整规则与已确认裁定见 [规则记录](docs/rules-decisions.md)。当前实现架构、已完成重构和后续计划见
[文档索引](docs/README.md)。

## 当前状态

主要游戏流程、实体牌组、功能牌、反应窗口、胜负判定、房间邀请、旁观、聊天、玩家互动、AI 玩家和断线处理均已实现，可以进行朋友间试玩。

目前房间只保存在服务器内存中：服务器重启或重新部署会结束正在进行的游戏。免费服务器闲置后首次打开可能需要约一分钟启动。

## 本地开发

需要 Node.js 22.12 或更高版本。

```powershell
npm ci
```

分别启动服务器和网页开发环境：

```powershell
npm run dev:server
npm run dev:client
```

然后打开 [http://localhost:5173](http://localhost:5173)。

提交前可运行：

```powershell
npm test
npm run typecheck
npm run build
```

AI 自对局和候选策略评估工具见 [AI Lab](src/ai-lab/README.md)。
